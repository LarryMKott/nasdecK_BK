## 三、构建与体积

```bash
cd frontend-vue
corepack enable          # pnpm 9.15.4（packageManager 字段指定）
pnpm install --frozen-lockfile
pnpm build               # 产物 → templates/vue/（2026-09-29 起为多文件：index.html + assets/*）
```

- 产物体积：~~1834KB 单文件~~ → 多文件（入口 HTML 2KB + 入口 JS 15KB + vendor 99KB + CSS 76KB + 12 个路由懒加载 chunk + 12 张插画 PNG 独立文件，合计约 1.6MB）
- 回滚：`git checkout v2.3.x -- templates/vue/` 即回旧界面（注意 v2.3.x 产物为单 index.html，回滚需连同后端 staticpages.py 一起回退）
